# Web-Based Placement System (Frontend)

This is a Vite + React frontend scaffold for the "web-based-placement-system" project.

## What I created
- React app scaffold with routing, components, layouts and pages (UI-only, dummy data).

## How to run
1. In the project root, install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the app in your browser at `http://localhost:5173`

Notes: This is frontend-only. No authentication, backend or database is implemented yet.
